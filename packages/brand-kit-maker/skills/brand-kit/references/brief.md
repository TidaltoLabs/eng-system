# 品牌需求清单

使用用户已给的信息填写本清单。缺失的非必要项可先留空并标为待定。

| 项目 | 需要的内容 |
|---|---|
| 品牌名称 | 精确拼写、大小写、空格、语言、是否允许断行 |
| 副标题 | 原文、标准拼写、可选的译意、是否需要单独字图 |
| 使用场景 | 站点标签、导航、登录页、桌面图标或其他用途 |
| 品牌背景 | 受众、产品定位、名称故事与设计意象 |
| 视觉限制 | 必须保留、可以简化、应避免的元素和风格 |
| 参考素材 | 附件及用途说明，区分供参考的图与必须保留的正式图 |
| 图形源文件 | 已确认的 PNG、原始尺寸、透明或可抠纯色背景；有旧稿时说明用哪个版本 |
| 配色 | 主色、辅助色、点缀色、实际应用背景、深浅底文字色 |
| 字体 | 名称和副标题字形、字重、所需字符、文件及允许随包分发的授权文本 |
| 输出范围 | 名称行数、组合方向、深浅底及字重矩阵、目标目录与用途 |

## 讨论记录

逐项写下选项、用户选定的结果和影响到的文件。确认项目包括 Logo 文件及透明处理、代表色与背景、准确文案、字体授权及排版、最终组合样张。

已有透明 PNG 时按原尺寸归档。纯色背景需提供精确 HEX，保留源稿并设置容差。图形内部出现相近颜色时，优先取得透明底稿。推荐源图最长边至少 1024 px，只有小图时应说明放大只能改变尺寸。每次修改都从选定的源图继续，保留独立版本供对照。
