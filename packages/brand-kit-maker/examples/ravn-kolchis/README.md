# Ravn Kolchis 品牌素材

以金羊毛和渡鸦组成主图，把 RK 的线索藏在图形中。青玉绿与暖金为主，浅蓝只作点缀。

副标题为 *Pretium laborum non vile*。

## 示例文件

| 文件 | 用途 |
|---|---|
| [Logo 源图](logo/README.md) | 可抠图底稿与透明定稿 |
| [组合说明](brand-kit/README.md)和[预览](brand-kit/preview.png) | 12 种定稿组合的浅底与深底展示 |
| [定稿配置](brand.json) | 源图、色板、文字、字重与布局 |
| [制作记录](process/README.md) | Logo、配色、文案及字体排版取舍 |

按[插件使用说明](../../README.md#典型用法)运行导出，生成紧裁图、透明母图、14 种尺寸的 PNG、两套 ICO、13 张独立元素图和 12 张图文组合，以及各目录的 README。

## 字体

采用 **Cormorant Garamond**。名称使用常规字形，副标题使用斜体。导出时使用[插件附带的字体及授权](../../assets/fonts/README.md)。
