# 定稿与交付

## 评审表

| 确认项 | 评审时展示 | 写入配置 |
|---|---|---|
| Logo | 定稿源图、透明抠图、实际背景和小图 | `logo`、`approval.logo` |
| 配色 | 色板、浅底与深底样张 | `palette`、`surfaces`、`approval.palette` |
| 文案 | 精确名称、副标题和双行断点 | `name`、`subtitle`、`twoLineName`、`approval.copy` |
| 字体与排版 | 字体、授权、字重、图文间距、组合矩阵 | `font`、`weights`、`layouts`、`approval.typography` |
| 交付样张 | 透明成品的浅底和深底效果及完整导出菜单 | `approval.proof` |

预览如果涉及截断、错字、字体缺字、透明边缘残色或文字对比不足，先修配置或源素材，再确认样张。用户批准的旧版可作为回退底稿。已确认的文案和图形资产直接沿用。

## 输出规格

- 原图按字节归档。默认透明清理保留抗锯齿，只有确认后才提高 alpha 阈值。紧裁图默认留 8 px 透明边距。方形母图居中，并保留四周留白。
- 正方形透明 PNG 默认为 16、24、32、48、64、96、128、180、192、256、384、512、1024、1280 px。网站 favicon 内含 16、32、48 px。Windows ICO 内含 16、24、32、48、64、128、256 px。
- 独立元素包括图形、每种名称排法及可选的副标题。标准组合为横排单行与竖排单行。允许断行时可增加竖排双行。每个布局各有深浅底和两档字重。
- 正式字图和图文组合为透明 PNG。带实色背景的预览图用于选样。深浅底文件名指文字配色。名称与副标题分别缩放，避免窄栏文字被截断。
- 总 README 汇总色板、字体、规格和选用指引。Logo 与图文素材分目录说明。原稿、多尺寸 PNG、ICO、独立元素、组合图和字体目录各有 README，包含实际文件链接。

## 配置约定

配置中的本地文件路径相对于配置文件，也可使用绝对路径。默认字体路径为空会使用插件附带的授权字体。自有字体须同时提供字体文件与许可文本。所有 `approval` 字段使用 JSON 布尔值。定稿生成的配置会更新为包内素材路径，可以从成品重新导出。

`logo.mode` 为 `alpha` 或 `color-key`。色键仅面向与主体分离的纯色。容差与羽化按 RGB 最大通道色差计算，建议用样张检视边缘。指定 `logo.archive` 可留档额外底稿。留空 `subtitle` 时，脚本只生成名称字图。
