# Ravn Kolchis 制作记录

| 讨论 | 确认的设计 |
|---|---|
| Logo | 以金羊毛为主体，渡鸦作为无眼剪影。RK 融入形态，不额外叠加显眼字母。 |
| 配色 | 将渡鸦调为明亮青玉绿，金羊毛用暖金。顺着羊毛曲线留一缕淡蓝。 |
| 文案 | 名称写作 Ravn Kolchis。铭文为 *Pretium laborum non vile*。竖排允许在两个词之间断行。 |
| 字体 | Cormorant Garamond。名称用常规字形、副标题用斜体。评审后增大字号和字重，缩短横排图文间距，并拉开竖排 Logo 和名称。 |
| 样张和交付 | 横排单行、竖排单行和竖排双行各四种字重与底色搭配，最终确定 12 种透明组合。 |
