# Brand Kit Maker

Turn brand requirements and design discussions (logo, color palette, copy, and typography) into a finalized configuration and export an archive-ready web brand kit.

> **Supported hosts**: Claude Code & Codex (requires native image-generation capability in the host session). Export scripts run on Windows PowerShell 7.

## Typical Usage

Start a Claude Code or Codex session with the plugin enabled, describe your brand requirements (or provide an existing logo and specify which elements to iterate on), and review visual proofs for logo, palette, copy, typography, and lockups. You can also run the export scripts locally on Windows with PowerShell 7:

```powershell
pwsh -File ./scripts/export-brand-kit.ps1 -ConfigPath ./examples/ravn-kolchis/brand.json -OutputDir ./rk-preview -PreviewOnly
pwsh -File ./scripts/export-brand-kit.ps1 -ConfigPath ./examples/ravn-kolchis/brand.json -OutputDir ./rk-delivery -DiscussionPath process/README.md
```

The bundled example preview shows the historical sign-off. Re-exporting preserves its palette, copy, layouts, and canvas sizes; exact text placement and tight-crop margins may vary slightly.
