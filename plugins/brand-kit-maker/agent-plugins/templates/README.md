# 品牌制作模板

- [需求清单](../skills/brand-kit/references/brief.md) 用于首次讨论，也可作为新项目的说明模板。
- [brand.json](brand.json) 保存生产参数，确认后可传入导出脚本。
- [discussion.md](discussion.md) 用于记录四项设计决策与最终样张。
- [交付约定](../skills/brand-kit/references/delivery.md) 规定配置字段与产物。各目录的 README 由 [说明生成脚本](../scripts/write-brand-readmes.ps1) 按实际文件生成。
